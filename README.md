# CatConsole!

Small little project I started in 10th grade. Includes an attempt at a text-based virtual filesystem that the user (hopefully) shouldn't ever have to interact with directly. Also some secret mini-programs that can be directly accessed from the "Console" (if you look around in the code they shouldn't be very hard to find)

Run it with python3 CatConsole.py
